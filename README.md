# Osama Ali Portfolio

My personal portfolio website as a Frontend Developer based in Alexandria, Egypt.

The website includes my introduction, education, skills, selected projects, career focus, and contact information.

## Live Website

[Open my portfolio](https://osamaalidev.github.io/Osama_Ali_Portfolio/)

## Run Locally

Open `index.html` directly in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project Structure

```text
index.html       Main page
css/style.css    Website styles
js/script.js     Website interactions
README.md        Project information
```
